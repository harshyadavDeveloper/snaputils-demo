## What is snaputils?

`@dungeonmaster/snaputils` is a lightweight, zero-dependency utility library for JavaScript and React apps. This playground lets you interact with every utility function in real time — just type an input and see the output instantly.

---

## Utilities Covered

| Category      | Functions                                                                                                                                |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 🧵 String     | `capitalize`, `truncate`, `toCamelCase`, `toTitleCase`, `maskString`, `wordCount`, `isPalindrome`, `countOccurrences`, `reverseString`   |
| 🔢 Number     | `formatCurrency`, `formatNumber`, `formatPercent`, `abbreviateNumber`, `roundTo`, `isEven`, `isOdd`, `randomBetween`, `formatFileSize`   |
| 📅 Date       | `formatDate`, `formatShortDate`, `timeAgo`, `isToday`, `daysBetween`, `addDays`, `isWeekend`, `isLeapYear`, `getDayName`, `getMonthName` |
| ✅ Validation | `isEmail`, `isURL`, `isPhoneNumber`                                                                                                      |
| 🔗 Array      | `unique`, `groupBy`, `chunk`                                                                                                             |
| 🔧 Object     | `omit`, `pick`, `deepClone`                                                                                                              |
| 🎨 Color      | `hexToRgb`, `rgbToHex`, `isValidHex`, `lightenColor`, `darkenColor`                                                                      |

## Running Locally

```bash
git clone https://github.com/harshyadavDeveloper/snaputils-demo.git
cd snaputils-demo
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173)
